<h1> 📚 Study Buddy</h1>
<p>An AI-powered study assistant that helps you learn smarter by generating quizzes from topics, chats, and documents. Perfect for students who want interactive and efficient learning.</p>

<br>

<h2>🚀 Live Demo </h2>
<p>
👉 <strong>
  <a href="https://huggingface.co/spaces/wovom/QuizGenie" target="_blank">
    Try it here
  </a>
</strong>
</p>
<br>

<h2>✨ Features</h2>
<ul>
  <li>🧠 Generate quizzes from any topic</li>
  <li>💬 Chat with AI to learn concepts</li>
  <li>📝 Create quizzes directly from chat</li>
  <li>📄 Upload documents and generate quizzes</li>
  <li>📊 View results and track performance</li>
</ul>
